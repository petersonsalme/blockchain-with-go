How to read this page. The mempool holds transactions this node accepted but no block has included yet.

Order
highest fee rate per byte first. This is the order mining takes them, so a higher fee gets in sooner.
Fee
the sum of the inputs minus the sum of the outputs; the miner collects it.
Per node
every node keeps its own pool. Gossip spreads transactions, so the pools should match within moments.
Leaving the pool
when a block includes a transaction it disappears from here and shows up in Blocks.
