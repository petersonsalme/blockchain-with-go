How to read this page. Each section is one node, as it reports itself.

Engine
pow: a block is sealed by finding a hash with enough leading zero bits. poa: a block is signed by any key of a fixed validator set; there is no turn order.
Difficulty
the leading zero bits a PoW block hash must have. It starts at the initial difficulty and, every retarget interval, moves toward the target block time.
Block work
2^difficulty, the hashes a miner expects to try. A PoA block weighs 1.
Chain work
the sum of block work from genesis to the tip. When nodes disagree on the tip, the reorg rule keeps the chain with the most work.
