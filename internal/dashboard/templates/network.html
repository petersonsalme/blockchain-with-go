How to read this page. It refreshes every 2 seconds and only reads the nodes; it never changes them.

Green
every reachable node is on the same tip: the network agrees.
Amber
syncing: nodes are at different heights, or at the same height with different tips for fewer than three polls (two nodes may just have mined at once).
Red
fork: nodes stay on different tips at the same height for three or more polls; or no node answers.
Height
the highest block among the reachable nodes.
Agree
nodes on the most common tip, out of all configured nodes.
Reachable
nodes that answered the last poll.
Mempool
transactions waiting to be mined: the largest pool among the reachable nodes, not the sum, because gossip puts the same transaction in every pool. The matrix shows each node's pool.
≠
this tip differs from the majority (only when a fork is confirmed), or this mempool size differs from the most common one (usually for a tick or two while a transaction spreads).
Behind by N
the node trails the highest one by N blocks and is catching up.
Unreachable
the node did not answer; its last known height is kept.
Chain per node
the last 8 heights up to the highest reachable node, one lane per node, so blocks at the same height line up.
● tip, ▲ behind
the node's last block, at the top height or below it.
⑂ fork
the block differs from the chain of the majority tip at that height. A node's own tip at the top height is marked only once the fork is confirmed; two nodes may just have mined at once.
Dashed
a height the node does not have, or the last known blocks of a node that does not answer.

A hash is cut in the middle to fit: hover it for the full value, or open it to see the block.
