How to read this page. The chain stored by this node, 20 blocks per page.

Height
the position in the chain; 0 is the genesis block.
Hash
identifies the block. It covers the header, including the Merkle root of the transactions.
Transactions
how many the block carries. In a mined block the first one is the coinbase, the miner's reward.
Validator
set only with proof of authority; proof-of-work blocks have none.
