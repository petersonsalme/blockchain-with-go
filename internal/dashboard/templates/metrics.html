How to read this page. Figures each node publishes at its own /metrics; the dashboard only reads them.

Blocks
how many blocks the node holds.
Mean mining time
time spent per block this node mined. "n/a" means it never mined one; only miners have a value.
HTTP 2xx, 4xx, 5xx, 429
requests answered since the node started: successes, client errors, server errors and rate-limited requests.
Block interval
seconds between consecutive blocks of the chosen node.
Height of each node
overlapping lines mean the nodes agree; a line below the others is a node that trails.
