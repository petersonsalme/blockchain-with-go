How to read this page. One transaction and the block that includes it.

Inputs
outputs of earlier transactions that this one spends (the UTXO model). A coinbase or genesis transaction has none.
Outputs
new coins assigned to an address, shown in coins (1 coin = 10^8 base units; hover an amount for the exact count). An output stays unspent until a later transaction uses it, whole.
Fee
inputs minus outputs; it goes to the miner.
Merkle proof
shows the transaction is in the block without listing the others: hash the leaf together with each sibling on the path (side = left or right) up to the root, which must equal the block's Merkle root. An empty path means it is the only transaction.
